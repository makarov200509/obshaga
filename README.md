# Общага — учебный тренажёр

Статический сайт с разделами, вложенными папками, теорией, тестами, вводом терминов и встроенной админкой. Работает на GitHub Pages без сервера, npm и ручного деплоя.

## Публикация (один раз)

1. Создайте новый **Public** репозиторий на GitHub, например `obshaga`.
2. Нажмите **Add file → Upload files** и перетащите в репозиторий `index.html`, `style.css`, `app.js`, `data.json` (не ZIP-архив). Нажмите **Commit changes**.
3. Откройте **Settings → Pages → Build and deployment**. В **Source** выберите **Deploy from a branch**, в **Branch** выберите `main` и `/ (root)`, нажмите **Save**.
4. Подождите несколько минут. Адрес: `https://ВАШ-ЛОГИН.github.io/obshaga/` (замените `obshaga` на имя репозитория).

## Как включить публикацию из админки

1. GitHub → **Settings** (настройки аккаунта) → **Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. Установите **Repository access: Only select repositories** и выберите только репозиторий сайта.
3. В **Repository permissions** дайте **Contents: Read and write**. Остальные разрешения не нужны. Установите срок действия токена и создайте его.
4. Откройте сайт → **Админка**. Укажите логин GitHub, имя репозитория, ветку `main` и токен. Создайте/измените разделы, папки, уроки и нажмите **Опубликовать на GitHub**.
5. Админка обновит `data.json` через GitHub API. GitHub Pages автоматически опубликует обновление. **Никаких команд или ручного деплоя не нужно.**

**Важно:** Это клиентская админка, а не защищённый серверный кабинет. Любой посетитель может открыть экран админки, но без токена с правами записи он не сможет опубликовать изменения в ваш репозиторий. Никому не передавайте токен, не вставляйте его в исходные файлы и не вводите на чужом устройстве. Токен сохраняется в `sessionStorage` только текущей вкладки. Чтобы убрать токен, закройте вкладку. GitHub Pages публичный: не добавляйте секретные материалы или персональные данные в `data.json`.

**Ограничения:** Прогресс учеников хранится только в их браузере (`localStorage`), между устройствами не синхронизируется. Telegram-авторизация, общая статистика и закрытые материалы потребуют внешнего сервера/базы данных. На GitHub Pages этого нет.

## Резервное копирование

В админке есть кнопка **Скачать резервную копию JSON**. Также вся история изменений доступна в GitHub.
