# Общага — GitHub Pages

Загрузите в корень репозитория `index.html`, `style.css`, `app.js`, `data.json` и папку `admin` с `index.html`. В GitHub Pages выберите ветку main и /(root).

Ученический сайт: https://makarov200509.github.io/obshaga/
Редактор: https://makarov200509.github.io/obshaga/admin/

## Доступ

В редакторе нужно ввести fine-grained GitHub personal access token аккаунта `makarov200509`, ограниченный репозиторием `obshaga`, с разрешением Contents: Read and write. Приложение проверяет владельца токена через GitHub API и право записи в репозиторий. GitHub повторно проверяет права при публикации. Токен хранится только в памяти открытой вкладки и не записывается в файлы или localStorage. Не делитесь им.

Важно: поскольку GitHub Pages публичен, любой может открыть адрес редактора и изучить его код, но без GitHub-доступа не сможет публиковать или удалять материалы в репозитории. Права GitHub — настоящая защита; скрытие кнопки — только удобство интерфейса. Владелец репозитория также может изменять файлы непосредственно через GitHub.

После изменения материалов нажмите «Опубликовать на GitHub». Данные учеников о прогрессе хранятся локально в их браузерах.

## Обновление редактора

- Урок можно разместить прямо в разделе: при создании выберите раздел и «Без папки».
- В вопросе «Несколько ответов» добавляйте варианты кнопкой «Добавить вариант» и отмечайте правильные флажками. Для зачёта ученик должен выбрать все правильные и ни одного лишнего.
- В теории доступны маркированные списки, списки 1. и 1), изображения и простые схемы. Для схемы дочерние элементы вводятся через точку с запятой.
- Фото загружаются как встроенные данные в `data.json`, поэтому установлен предел 300 КБ на изображение. Большое число фото может сделать `data.json` слишком тяжёлым для GitHub API. Перед редактированием делайте резервную копию JSON.
- Существующие уроки и данные сохранены. Изменения становятся общедоступными только после публикации через GitHub.
